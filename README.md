# cybersecurite-portfolio

Bienvenue sur mon portfolio cybersécurité.

Ce dépôt présente plusieurs projets réalisés dans le cadre
de mon apprentissage en cybersécurité, du niveau débutant
au niveau avancé.

## Objectifs
- Comprendre les bases de la sécurité informatique
- Mettre en pratique des outils et méthodes cyber
- Me préparer à une L3 professionnelle / alternance

## Outils utilisés
- Linux
- Python
- Bash
- Nmap
- Concepts cybersécurité (réseau, web, système)

## Projets
1. Sécurité des mots de passe
2. Scan réseau
3. Vulnérabilités web
4. Analyse de logs
5. Infrastructure sécurisée
