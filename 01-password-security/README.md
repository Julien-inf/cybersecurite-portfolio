# 🔐 Projet 1 – Sécurité des mots de passe

## Objectif
Comprendre pourquoi les mots de passe faibles sont dangereux
et comment les sécuriser.

## Contenu
- Vérification de la force d’un mot de passe
- Utilisation de hash (SHA-256 / bcrypt)
- Bonnes pratiques de sécurité

## Compétences acquises
- Bases de la cybersécurité
- hash sécurisé avec SHA-256 et bcrypt
- Notions de hashage
- Python

## Ce que j’ai appris
Les mots de passe doivent être longs, uniques et jamais stockés
en clair.
